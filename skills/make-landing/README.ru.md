# make-landing

[![en](https://img.shields.io/badge/lang-en-blue.svg)](README.md)
[![ru](https://img.shields.io/badge/lang-ru-green.svg)](README.ru.md)

Несколько самостоятельных вариантов лендинга, героя, обложки или слайдов с выбором по готовым preview. У каждого свой визуальный референс и автор, полный design.md с UTC/SHA-256 до кода и проверка в браузере или экспорте.

```text
/make-landing
```

Или: «варианты дизайна», «несколько вариантов лендинга на выбор», «редизайн». Укажи поверхность и число вариантов; если числа нет, скилл уточнит его.

1. Общий контент фиксируется в брифе, разные референсы распределяются через матрицу направлений.
2. Свой автор на вариант: по умолчанию Codex CLI, при недоступности — субагент.
3. Полная концепция замораживается, затем автор реализует, проверяет и снимает результат.
4. Галерея открывается рядом; картинки приходят в чат по готовности каждого варианта.
5. Человек выбирает победителей, второй раунд смешивает их сильные элементы, выбранная версия переносится в канон проекта.

Исходные концепции сохраняются; дальнейшие решения записываются в amendments. Веб-кадры по умолчанию 1440×900, узкий layout проверяется отдельно. Обложки и слайды имеют заданные размеры. Доступность CLI и инструментов preview/экспорта определяет выполнимые шаги; ограничения указываются в отчёте.

Из папки скилла, когда в папке варианта уже есть design.md:

```sh
python3 scripts/freeze_concept.py freeze <папка-варианта>
python3 scripts/freeze_concept.py verify <папка-варианта>
```

Установка — через [плагин репозитория](../../README.ru.md) или копирование всей папки make-landing в каталог скиллов харнесса. Процесс в [SKILL.md](SKILL.md), [роль автора](references/author.md) и [шаблон design.md](references/design-template.md) входят в комплект.
