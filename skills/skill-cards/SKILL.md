# Карточки скиллов

Карточка объясняет новичку один скилл: что он делает, чем помогает и в каком порядке работает. Одна карточка на один скилл, формат 1080×1920. Это учебный материал, а не отчёт: цифр-наград на ней нет.

## Что на карточке

Сверху вниз, все блоки обязательные:

| Блок | Содержание | Лимит |
|---|---|---|
| Шапка | чёрный стикер `/имя-скилла` и подпись штаба в одну строку | подпись до 30 знаков |
| Заголовок | русское имя скилла | до 10 знаков, одна строка |
| Что делает | абзац, начинается с синего «Что делает:» | 2 строки, около 110 знаков |
| Чем помогает | 3 плитки: польза и одна фраза о ней | заголовок до 18, фраза до 60 знаков |
| Как работает <имя> | 3 колонки «01 · ЭТАП», по 3 или 4 правила | правило до 36 знаков |
| Порядок работы | схема: ряд шагов, проверка, ветка, возврат | до 6 шагов в ряду |
| Главное правило | чёрный блок: правило своими словами и источник | 2 строки |
| Подвал | девиз слева, путь к SKILL.md справа | одна строка |

## Порядок работы

1. **Источник.** Прочитай SKILL.md скилла и его `references/`. Всё содержание карточки берётся только оттуда. Чего в источнике нет, ставь плейсхолдером в квадратных скобках (`[ЦИТАТА]`, `[ПУТЬ]`) и в конце скажи человеку, что дописать.
2. **Подпись штаба.** Возьми из правил штаба (`AGENTS.md` или `CLAUDE.md`), например «АГЕНТ RIS © CORP». Нет в правилах: спроси один раз.
3. **Текст.** Заполни таблицу выше. Пройди по правилам языка ниже.
4. **Схема.** Найди в скилле порядок шагов, одну проверку (ворота, после которых работа считается сделанной), одну ветку и один возврат. Разложи по сетке из [references/diagram.md](references/diagram.md): там же формулы стрелок и три готовые раскладки.
5. **Сборка.** Скопируй [assets/card-template.html](assets/card-template.html) и замени содержание. Стили не трогай: размеры подобраны под высоту 1920.
6. **Проверка.** `node scripts/render_card.js карточка.html`: скрипт сохранит PNG рядом и скажет запас по высоте. Переполнение или запас меньше 24 px: сокращай текст, шрифт не уменьшай. Посмотри на PNG сам.
7. **Сдача.** Где делать, ниже.

## Правила языка

- **Учебная, не отчётная.** Не пиши, сколько задач закрыли и сколько правил в скилле. Вместо цифр блок «Чем помогает»: что станет лучше у того, кто включит скилл.
- **По-русски.** issue → задача, Proof → доказательство, тело issue → описание задачи, $HOME → диск, коллектор → сбор данных. Латиницей остаются только команда в стикере, пути к файлам и названия продуктов (GitHub).
- **Без тире.** Ни длинного «—», ни короткого «–». Вместо них двоеточие, запятая, вопрос или новая фраза: «Нет файла? Так и говорим», «Второй шаг: дочерняя задача». Дефис внутри слова можно.
- **Без людей в подписях.** Не «слово фаундера», а источник в самом скилле: «Правило 16 скилла «Ретро»», «Правило скилла с 28.10.2026». Пересказ без кавычек, кавычки только у дословной цитаты.
- **Термины штаба** (штаб, канон, прогон) оставляй, если ученик их знает. Не уверен: спроси, как объяснить.
- **Подписи на стрелках** короткие и по-русски: «нашёлся такой же», «доказательство есть», «недоделки в новые задачи».

## Стиль

| Токен | Значение |
|---|---|
| Рамка | `#F2D5CD`, поле 48 px |
| Карточка | `#F8F8F8`, радиус 40, отступы 64 / 64 / 56, между блоками 40 |
| Плитки и колонки | `#FFFFFF`, радиус 24 |
| Текст | `#141414`, вторичный `#4A4A50` и `#55555A` |
| Акцент | `#2E3BDB`: «Что делает:», номера этапов, шаг-проверка, возврат на схеме |
| Главное правило | фон `#141414`, текст белый, источник `#FF7AA2` |
| Шрифты | Unbounded 800 и 900 для заголовков, Inter для текста, JetBrains Mono для стикера, подписей и этапов |
| Размеры | заголовок 104, разделы 34, абзац 26, плитки 20 / 18, правила 20, схема 17 / 13 |

Стикер чуть повёрнут (`rotate(-1.5deg)`), имя команды со слешем. Подпись штаба стоит в той же строке, отдельной строкой её не ставим.

## Где делать

- **Холст Design в Claude**, если он есть: одна карточка = один артборд 1080×1920, 80 px между артбордами в ряд. Разметку шаблона переносим в `.dc.html`: в `<head>` строка `<script src="./support.js"></script>`; тело оборачиваем в `<x-dc>`; ссылку на шрифты и `<style>` кладём в `<helmet>` внутри `<x-dc>`; в конце `<body>` блок `<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":1080,"height":1920}}'>` с `class Component extends DCLogic { renderVals() { return {}; } }`. Схема из отдельных элементов, тогда каждый блок и стрелку можно сдвинуть руками.
- **Без холста**: HTML-файл по шаблону и PNG из `scripts/render_card.js`. Скрипту нужен Playwright с Chromium: `npm i -D playwright && npx playwright install chromium`. Без доступа к Google Fonts скрипт предупредит, что замер приблизительный.

## Частые ошибки

| Ошибка | Как правильно |
|---|---|
| Цифры-награды: «224 задачи», «11 правил» | Блок «Чем помогает» с пользой для ученика |
| Четыре подписи столбиком: надзаголовок, стикер, заголовок, «ЧТО ДЕЛАЕТ» | Стикер и подпись штаба в одну строку, «Что делает:» внутри абзаца |
| Стикер без слеша | `/manager`: это команда, которую ученик наберёт |
| Английские слова и тире в тексте | Правила языка выше |
| Длинное слово не влезает в шаг схемы | Короче слово в блоке, пояснение на стрелке |
| Схема одним `<svg>` | Каждый блок и отрезок отдельным элементом |
| Выдуманный порядок или цитата | Плейсхолдер в скобках и вопрос человеку |
| Переполнение по высоте | Сократить текст до запаса от 24 px |
