# Схема «Порядок работы»

Схема показывает механизм скилла: ряд шагов, одну проверку, одну ветку и один возврат. Больше элементов ученик не прочитает.

## Основа

- Схема живёт в блоке-хосте: `<div style="position: relative; width: 852px; height: 256px; flex-shrink: 0">`. Каждый блок, стрелка и подпись внутри стоят через `position: absolute; left; top` в целых px.
- Каждый элемент отдельный: блок это `<div>`, стрелка это маленький `<svg>` на один прямой отрезок. Одним большим `<svg>` схему не рисуем: на холсте Design такую схему не сдвинуть и не поправить по частям.
- Порядок в файле: сначала все стрелки, потом блоки, потом подписи. Позже в файле значит выше и ловит клик.
- Текст блока внутри одного `<span>`, переносы через `<br>`, без вложенных `<div>`.

## Сетка

Главный ряд: 6 блоков 102×88 с шагом 150 (зазор 48).

| Шаг | left | центр x |
|---|---|---|
| 01 | 0 | 51 |
| 02 | 150 | 201 |
| 03 | 300 | 351 |
| 04 | 450 | 501 |
| 05 | 600 | 651 |
| 06 | 750 | 801 |

- Ряд: `top: 0`, центр y = 44, низ = 88.
- Второй ряд: `top: 184`, высота 72, центр y = 220.
- Середина зазора между рядами: y = 136.
- В блок 102 px влезает слово до 8 букв при 17 px. Длиннее: другое слово («проверка», а не «доказательство»), а пояснение на стрелку.

## Виды блоков

Общее для всех: `position: absolute; box-sizing: border-box; padding: 8px; display: flex; align-items: center; justify-content: center; text-align: center; border-radius: 16px; font-size: 17px; line-height: 1.25`.

| Вид | Фон и рамка | Текст |
|---|---|---|
| Шаг | `#FFFFFF`, `1.5px solid #141414` | номер mono 13 px `#2E3BDB`, `<br>`, имя 600 |
| Проверка (ворота) | `#2E3BDB`, рамка того же цвета | белый, номер `#C9CDFF` |
| Конец | `#141414` | белый 700, номер `#FF7AA2` |
| Исход ветки | как шаг, `font-weight: 400` | `<b>Итог</b><br>пояснение` |
| Запрещённый путь | фон карточки `#F8F8F8`, `1.5px dashed #8A8A90` | `#5A5A60`, текст в `<s>` |
| Развилка-ромб | `#2E3BDB`, без рамки, `clip-path: polygon(50% 0, 100% 50%, 50% 100%, 0 50%)`, ширина 168 | белый 600, вопрос с «?» |
| Ответ-список | `#141414`, `text-align: left`, `justify-content: flex-start` | строки через `<br>` |

Блок шага целиком:

```html
<div style="position: absolute; left: 150px; top: 0px; width: 102px; height: 88px; box-sizing: border-box; padding: 8px; display: flex; align-items: center; justify-content: center; text-align: center; background: #FFFFFF; border: 1.5px solid #141414; border-radius: 16px; font-size: 17px; line-height: 1.25; font-weight: 600; color: #141414"><span><span style="font-family: 'JetBrains Mono', monospace; font-size: 13px; font-weight: 700; color: #2E3BDB">02</span><br>поиск похожих</span></div>
```

## Стрелки

Один `<svg>` на один прямой отрезок, толщина коробки 8 px, линия по её середине. Наконечник через `<marker>`, у каждой стрелки свой `id`: `dc-arrow-head-filled-1`, `-2` и дальше.

Возьми (x, y) как левый конец отрезка (верхний, если вертикальный), n как длину, h = 4 при наконечнике и 0 без него.

| Направление | Коробка svg | path |
|---|---|---|
| вправо | `left: x; top: y−4; width: n; height: 8` | `M 0 4 L n−h 4` |
| влево | то же | `M n 4 L h 4` |
| вниз | `left: x−4; top: y; width: 8; height: n` | `M 4 0 L 4 n−h` |
| вверх | то же | `M 4 n L 4 h` |

- Остриё останавливается за 1 px до блока: стрелка от правого края шага 01 (x = 102) до шага 02 (x = 150) имеет длину 47.
- Атрибуты `width`/`height`, `viewBox` и `width`/`height` в стиле всегда одинаковые.
- Ломаная стрелка: несколько отрезков подряд, конец одного это начало следующего, наконечник только у последнего.
- Основной поток: `#141414`, сплошная. Возврат: `#2E3BDB`, `stroke-dasharray: 6 6`. Запрещённый путь: `#8A8A90`, пунктир, без наконечника.

Стрелка вправо между шагами 01 и 02:

```html
<svg width="47" height="8" viewBox="0 0 47 8" preserveAspectRatio="none" style="position: absolute; left: 102px; top: 40px; width: 47px; height: 8px; overflow: visible; fill: none; stroke: #141414; stroke-width: 2; stroke-linecap: round; stroke-linejoin: round"><defs><marker id="dc-arrow-head-filled-1" orient="auto" markerWidth="5" markerHeight="5" refX="2" refY="2" overflow="visible"><path d="M0 0 L4 2 L0 4 Z" fill="#141414" stroke="none" style="stroke: none; fill: #141414; fill: context-stroke"/></marker></defs><path d="M 0 4 L 43 4" marker-end="url(#dc-arrow-head-filled-1)"></path></svg>
```

Линия без наконечника: тот же `<svg>` без `<defs>` и без `marker-end`.

## Подписи

- `position: absolute; text-align: center; font-family: 'JetBrains Mono', monospace; font-size: 13px; line-height: 16px; color: #55555A`. Подпись возврата синяя.
- Ширина: около 8 px на знак плюс 8, не шире зазора.
- Над горизонтальной линией на высоте y: `top = y − 28`. Под ней: `top = y + 12`.
- Рядом с вертикальной линией x: справа `left = x + 12`, слева правый край на `x − 12`. `top` = середина отрезка − 8.
- Подпись не ближе 8 px к любой линии и блоку. Пишем по-русски, коротко: «нашёлся такой же», «доказательство есть», «да», «нет».

## Готовые раскладки

### Ряд + ветка + проверка + возврат (менеджер)

- Ряд из 6 шагов, шаг 06 «проверка» синий.
- Ветка вниз из шага 02: вертикаль `left: 197; top: 88; height: 95`, исход «Дубль / закрываем сразу» `left: 113; top: 184; 176×72`, подпись слева `left: 53; top: 128; width: 136`.
- Из проверки вниз в конец: вертикаль `left: 797; top: 88; height: 95`, блок «Закрыто» `left: 750; top: 184; 102×72`, подпись слева `left: 633; top: 128; width: 156`.
- Возврат из «Закрыто» в шаг 03, синий пунктир: отрезок влево `left: 351; top: 216; width: 399` без наконечника, затем вверх `left: 347; top: 89; height: 131` с наконечником. Подпись над линией `left: 452; top: 192; width: 196`.

### Ряд + развилка на два исхода (ретро)

- Шаг 03 «обещания» синий.
- Линия вниз из шага 03 до середины зазора: `left: 347; top: 88; height: 48`, без наконечника.
- Поперечная линия между центрами исходов: `left: 201; top: 132; width: 300`.
- Две стрелки вниз в исходы: `left: 197` и `left: 497`, `top: 136; height: 47`.
- Исходы «Сделано» `left: 150` и «Мимо» `left: 450`, `top: 184; 102×72`. От «Мимо» стрелка вправо в правило `left: 600; 150×72`.
- Подпись между стрелками под поперечной линией: `left: 267; top: 148; width: 168`, текст `<s>частично</s> не бывает`.

### Вопрос + развилка-ромб + ответ (дейли)

- Ряд по центру y = 72: шаги 01 и 02 `top: 28`, ромб «файл дня?» `left: 300; top: 28; 168×88`.
- «да» вправо: стрелка `left: 468; top: 68; width: 103` в чёрный ответ-список `left: 572; top: 0; 280×144`, подпись `left: 504; top: 44; width: 32`.
- «нет» вниз: стрелка из нижней точки ромба `left: 380; top: 116; height: 67` в блок `left: 284; top: 184; 200×72`, подпись `left: 396; top: 141`.
- Запрещённый путь слева: пунктир `left: 184; top: 216; width: 100`, блок `left: 0; top: 184; 184×72` с зачёркнутым текстом, подпись «вместо» `left: 206; top: 192; width: 56`.
