# Интеграция с CRM (по желанию)

Справочник уровня 2. Читать, только если в конфиге задан `crm_path`, а issue коммерческий или связан с коммуникацией.

Включается заданием `crm_path` и `crm_pointer_format` в конфиге в твоём `AGENTS.md` / `CLAUDE.md`.

Когда интеграция CRM включена, тело каждого коммерческого или связанного с коммуникацией issue обязано содержать указатель на соответствующий артефакт CRM (карточку человека, карточку возможности, заметку встречи). Формат указателя по умолчанию — `[[<slug>]]` (вики-ссылка в стиле Obsidian), но можно настроить любой формат, который использует твоя CRM.

Для коммерческих и менторских треков держи деньги вне тела задачи на GitHub — цена, остаток пакета, статус оплачено/выиграно и язык закрытия сделки живут в CRM или в журнале продаж. Тело issue несёт `[[<slug>]]` и однострочный указатель вместо этого.

```markdown
**Track:** [[<opportunity-slug>]]
```

При включении manager проверяет, что путь CRM существует; если нет — показывает однострочное предупреждение и продолжает без требования указателя.
