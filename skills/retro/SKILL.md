# Retro

Запускается из штаба. Смотрит назад на неделю по задачам всех отделов.

## Правило данных

Каждый запуск читает файлы задач заново. Своей копии задач не держи и неделю из памяти чата не восстанавливай. Файл ретро это срез со ссылками, источник правды остаётся в задачах отделов.

## Шаги

1. Определи текущую ISO-неделю и её даты из системного времени. Если человек назвал другую неделю, возьми её.
2. Прочитай файл правил штаба (`CLAUDE.md` или `AGENTS.md`). Найди строки, где лежат задачи отделов, например:
   `Обучение: ../corp-learn. Задачи отдела лежат в ../corp-learn/tasks/.`
3. Если таких строк нет, остановись. Скажи, что в правилах штаба не указано, где лежат задачи отделов, и предложи дописать по строке на отдел в формате выше. Пути не угадывай.
4. Для каждого отдела прочитай его файл правил и задачи:
   - локальные файлы: `tasks/*.md`, кроме `README.md` и `_template.md`;
   - внешний источник (например GitHub Issues через `gh`): читай оттуда, если доступно;
   - если источник недоступен, запомни отдел как «не прочитано» с причиной.
5. Если задач нет ни в одном отделе, остановись: фактов для ретро недостаточно.
6. Разложи задачи недели:
   - «Сделано»: статус «принято», дата приёмки внутри недели;
   - «Застряло»: заблокированные, просроченные, без движения всю неделю;
   - «Снято»: снятые на этой неделе, с причиной.
7. Найди повторы: один и тот же блокер, одинаковый тип работы или одно решение человека, которое ждут несколько задач. Повтор это минимум два случая, иначе не пиши.
8. Запиши файл `tasks/retro-<ГГГГ>-W<NN>.md` в штабе. Если папки `tasks/` нет, создай её.

## Файл ретро

```markdown
# Ретро <ГГГГ>-W<NN> · <дата начала>..<дата конца>

## Сделано
- <отдел> · <задача>: <результат> · [файл](../../corp-learn/tasks/<файл>.md)

## Застряло
- <отдел> · <задача>: <блокер или с какой даты стоит> · <ссылка>

## Снято
- <отдел> · <задача>: <причина> · <ссылка>

## Повторяется
- <что повторяется>: <ссылки на 2+ задачи>

## Не прочитано
- <отдел>: <причина>
```

Ссылки относительные от файла ретро. Факты отдельно от выводов. Пустые разделы не пиши.

## Ответ в чат

3-5 строк выводов по фактам недели, путь к файлу ретро и один вопрос человеку: что из застрявшего снять, упростить или продолжить.

## Запрещено

- менять статусы и содержимое задач отделов без решения человека;
- скрывать застрявшее;
- придумывать результаты, если в задаче нет ссылки или приёмки;
- переходить к планированию следующей недели внутри ретро.
