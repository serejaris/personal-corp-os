# claude-sessions-sync

Синхронизация записей сессий Claude Code между двумя аккаунтами Anthropic в desktop-приложении Claude (macOS).

## Какую проблему решает

Приложение хранит список сессий по паре «аккаунт + организация» в
`~/Library/Application Support/Claude/claude-code-sessions/<accountUuid>/<orgUuid>/local_*.json`
и показывает только текущую пару. Появился второй аккаунт, переключил логин — и пикер почти пуст, хотя ничего не удалялось. Транскрипты (`~/.claude/projects/`) общие для всех аккаунтов; по аккаунтам разложены только записи.

Скилл зеркалит записи между двумя папками аккаунтов (двунаправленно,
побеждает свежая версия), объединяет флаги архивации и маркеры удалённых
и ведёт по процедуре безопасного переноса: приложение должно быть полностью
закрыто, пока двигаются файлы.

Типовой цикл, если держишь два аккаунта из-за лимитов:

1. Попросить агента синхронизировать сессии (этот скилл).
2. Переключить логин в приложении.
3. Все сессии снова в пикере.
