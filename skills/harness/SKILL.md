# /harness — режим работы агента

Человек задаёт, как агент работает в этой сессии, шапкой из четырёх строк. Модель каждый ставит свою: ту, что есть в его подписке и харнесе.

```
/harness
режим: оркестратор, критик
модель: <модель>
эффорт: низкий
макс: 3 субагента
```

Любую строку можно пропустить — тогда действует значение по умолчанию.

## Поля

**режим** — одна или несколько ролей через запятую:

| Роль | Что делает агент |
|---|---|
| исполнитель (по умолчанию) | делает работу сам |
| оркестратор | сам только планирует, режет работу на задачи, отдаёт их субагентам, собирает результат; файлы сам не правит |
| критик | перед тем как отдать результат человеку, проверяет его: открывает файлы, смотрит снимки, прогоняет проверки; называет, что не сделано |

«оркестратор, критик» — агент раздаёт работу субагентам и сам принимает её перед показом человеку.

**модель** — модель для субагентов. По умолчанию — модель текущей сессии; каждый ставит свою. Передавать её явно при каждом запуске субагента. Если в харнесе нет такой модели или субагентов — сказать об этом одной строкой и работать самому.

**эффорт** — глубина работы:

| Эффорт | Как работает агент |
|---|---|
| низкий | короткие ответы, минимум проверок сверх необходимого, без исследований по сторонам |
| средний (по умолчанию) | обычная работа: проверка результата перед сдачей |
| высокий | тщательно: исследование, варианты, полная проверка каждого шага |

Если харнес умеет выставлять эффорт модели (reasoning effort) — выставить; иначе держать глубину работы по таблице.

**макс** — сколько субагентов одновременно (по умолчанию 3). На одном проекте — не больше двух в одних файлах: у каждого своя зона, иначе они перетирают работу друг друга.

## Как применять

1. В начале ответа одной строкой подтвердить режим: `режим: оркестратор, критик · модель: … · эффорт: низкий · макс: 3`.
2. Держать режим до конца сессии или до новой шапки `/harness`.
3. Оркестратор: каждому субагенту — одна задача, своя зона файлов, критерий готовности; ждать уведомлений о завершении, а не опрашивать циклами.
4. Критик: не пересказывать отчёт субагента как факт — сверить с файлами и снимками; расхождения назвать человеку.
5. Оценок времени работы агентов не давать — вместо них порядок шагов и чем проверяется результат.
