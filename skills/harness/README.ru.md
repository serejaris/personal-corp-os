# Harness

Задаёт, как агент работает до конца сессии, одной шапкой в начале сообщения: роль (оркестратор, исполнитель, критик), модель субагентов, эффорт и лимит субагентов.

```
/harness
режим: оркестратор, критик
модель: <модель>
эффорт: низкий
макс: 3 субагента
```

- **режим** — исполнитель делает работу сам; оркестратор только планирует и раздаёт задачи субагентам; критик проверяет результат по файлам, снимкам и проверкам до показа тебе.
- **модель** — модель субагентов. По умолчанию — модель текущей сессии; каждый ставит свою.
- **эффорт** — низкая, средняя или высокая глубина работы.
- **макс** — сколько субагентов работает одновременно.

Любую строку можно пропустить — действует значение по умолчанию. Режим держится до конца сессии или до новой шапки `/harness`.
