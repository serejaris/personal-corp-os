# AGENTS.md Writer

![Иллюстрация скилла](assets/illustration.png)

Скилл пишет и чистит файл правил агента `AGENTS.md` для репозитория, штаба или отдела.

## Проблема

Файл правил разрастается: в нём копятся процедуры, история решений и правила подпапок. Рядом появляется второй файл `CLAUDE.md`, и Claude Code с Codex читают разные правила. Codex читает цепочку `AGENTS.md` с бюджетом 32 КБ и молча обрезает всё, что не влезло. Русский текст съедает этот бюджет примерно в полтора раза быстрее английского.

## Что делает

- Один файл правил на папку: `AGENTS.md`. `CLAUDE.md` и `.claude/rules/` сливает и убирает после подтверждения.
- Каждая строка — маршрут, граница или постоянное поведение. Процедуры уходят в скиллы, справки в `docs/`, история в git.
- Размер: старт 40–60 строк, потолок 200 строк и 32 КБ на всю цепочку от корня.
- Правила подпапки — во вложенный `AGENTS.md` и строка-маршрут в корне.
- Отдел первой строкой ссылается на штаб, где лежат глобальные правила.

## Установка

```bash
ln -s "$(pwd)/skills/agents-md-writer" ~/.claude/skills/agents-md-writer
```

Вызов: `/agents-md-writer`.

## Раньше

Скилл назывался `claude-md-writer` и строил `CLAUDE.md` с `.claude/rules/`. С 2026-10 Claude Code читает `AGENTS.md` сам, поэтому скилл переписан под один файл для всех харнесов.
