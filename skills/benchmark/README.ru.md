# Скилл Benchmark

Скилл, чтобы выбирать движки и модели для агентного пайплайна по замеру на своих данных.

## Проблема

Страница цен говорит, сколько стоит токен или час, но не говорит, сколько ошибок модель сделает на ваших встречах, сколько идёт прогон и во что обходится час записи целиком. Сравнение «на глаз» на ноутбуке смешивает время с остальной нагрузкой и не оставляет цифр, которые можно показать.

## Решение

- Один файл задачи перечисляет варианты: движки распознавания, модель-автор конспекта, модель-судья
- Скрипты гоняют варианты по одному в изолированном контейнере, ключи только из env-файла root 600
- Каждая LLM идёт в одном харнесе (Claude Code без интерфейса), меняется только модель
- Метрики: время, цена часа записи в долларах и рублях с источником и датой цены, WER/CER и точность терминов курса для распознавания, проверки кодом и судья другой модели для LLM-шагов
- Выход: `results.json`, `results.csv`, одна статичная страница с аналитикой без текста транскриптов

## Установка

```bash
cp -r skills/benchmark ~/.claude/skills/
```

На контейнере бенчмарка: `ffmpeg`, Python venv с `httpx jiwer faster-whisper`, Node и `@anthropic-ai/claude-code`.

## Краткий справочник

### Триггеры

| Фраза | Язык |
|-------|------|
| "бенчмарк", "сравни движки", "сколько стоит час записи" | RU |
| "benchmark the pipeline", "compare ASR engines" | EN |

### Команды

| Шаг | Команда |
|-----|---------|
| Распознавание | `python3 scripts/asr.py --task task.json --out runs/<name>` |
| LLM-варианты | `python3 scripts/llm.py --task task.json --out runs/<name> --stage author` |
| Судьи на другой машине | `python3 scripts/llm.py ... --stage judge` |
| Оценка | `python3 scripts/score.py --task task.json --out runs/<name> --prices prices.json` |
| Страница | `python3 scripts/report.py --results runs/<name>/results.json --out report.html` |

### Файлы

| Файл | Назначение |
|------|------------|
| `SKILL.md` | Правила, шаги, метрики, список искажений |
| `task.example.json` | Задача со всеми типами движков |
| `prices.example.json` | Таблица цен с источниками, проверено 30.09.2026 |
| `examples/adapter_example.py` | Минимальный адаптер LLM: автор, проверки, судья |
