# corp-new

[![en](https://img.shields.io/badge/lang-en-blue.svg)](README.md)
[![ru](https://img.shields.io/badge/lang-ru-green.svg)](README.ru.md)

Заводи отдел, когда работа в одном направлении повторяется и ты каждый раз объясняешь агенту одни и те же правила. `corp-new` создаст каркас и свяжет его со штабом: из штаба агент видит карту всей системы, из отдела читает правила твоего направления.

![Схема скилла](assets/illustration.svg)

Отдел — соседняя папка штаба со своими правилами, скиллами и задачами, например `corp-sales`. GitHub для него не нужен: отдел живёт в локальной папке.

```
/corp-new
```

Или словами: «создай отдел», «новый отдел», «заведи отдел продаж».

- Находит папку штаба (с `me.md` или `stack/harness.md`). Штаба нет — ставит его из [agent-starter](https://github.com/serejaris/agent-starter) и проходит скилл `hq` оттуда.
- Подбирает имя `corp-<домен>` и проверяет, что такой папки и записи в карте отделов ещё нет.
- Ставит каркас: `AGENTS.md` с пустыми местами для тебя, папки скиллов и задач `tasks/`, симлинки `CLAUDE.md` и `.claude/skills`, `git init`.
- Связывает штаб и отдел в правилах друг друга. Приватный репозиторий на GitHub через `gh` создаёт, только если попросишь.
- Отвечает таблицей шагов ✓/✗ и говорит, что заполнить дальше: назначение отдела и канон — какой файл за что отвечает. Заполняешь сам или вместе с агентом через `/grill-me`.

Правила отдела за тебя не пишет, чужие файлы не трогает, незакоммиченную работу не выбрасывает.
