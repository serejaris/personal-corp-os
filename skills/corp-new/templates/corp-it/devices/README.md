# Опись устройств

Здесь лежит по одному файлу на устройство: `devices/<имя>.md`. Имя короткое, латиницей, по словарю отдела: `laptop.md`, `server.md`, `printer.md`. Файл читается сверху вниз, у каждого раздела своя дата проверки.

Шаблон файла: `.agents/skills/device-inventory/template.md`. Файл заводит и обновляет скилл `device-inventory`: он снимает данные скриптом только для чтения и раскладывает их по разделам.

## С чего начать

Начни с одной машины, вашего ноутбука. Скажи агенту:

> Сними опись моего компьютера: модель, память, диск, ОС, что запускается при старте, уходит ли он в сон. Запиши в devices/<имя>.md без паролей и ключей. Если у меня есть вторая машина или сервер, спроси, как я на неё захожу, и запиши способ входа в скилл отдела так, чтобы новое окно могло зайти туда само. Приватный ключ не печатай и не копируй.

Без второй машины задание тоже имеет смысл: опись ноутбука отвечает на вопросы "почему тормозит" и "можно ли оставить его на ночь".

## Что не пишется в опись

- пароли, ключи, токены, recovery-ключи: только имя секрета и где он лежит;
- MAC-адреса, серийные номера, UUID;
- имя Wi-Fi и точный адрес;
- окружение процессов и значения переменных;
- живые числа до байта и время работы: пишутся классом.
