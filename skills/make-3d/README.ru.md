# make-3d

[![en](https://img.shields.io/badge/lang-en-blue.svg)](README.md)
[![ru](https://img.shields.io/badge/lang-ru-green.svg)](README.ru.md)

Делает 3D-модель для сцены: предмет, комнату, робота, офис. Вместо правок одной модели строит несколько вариантов и показывает их рядом. Подходит, когда уже ясно, что модель показывает и какие у неё состояния, но неясно, как она выглядит.

```
/make-3d
```

Или попроси: «сделай варианты модели», «как это может выглядеть в 3D».

- Изучает сцену: исходник, команду сборки, место, где рисуются объекты, живую страницу. Присылает снимок сцены в текущем виде.
- Собирает один набор демо-данных, в котором есть каждое состояние модели.
- Каждому варианту даёт свою копию сцены, порт и кеш сборки. Твою сцену не трогает, пока ты не выберешь вариант.
- Запускает исполнителей параллельно, по одному на вариант (по умолчанию Codex CLI, иначе субагент).
- Каждый вариант сдаёт одинаковые листы с одной камерой: `general.png` (вся сцена), `states.png` (сетка состояний с подписями), `detail.png` (крупный план детали, от которой зависит, читается ли модель).
- Присылает листы в чат картинками, затем короткое сравнение и рекомендацию. Выбираешь ты.
- Переносит выбранный вариант в твою сцену на настоящих данных, пишет тесты на правила состояний и присылает финальные листы.

Сцена показывает факты, а не содержимое: имена файлов и флаги состояния. Содержимого файлов и адресов репозиториев в ней нет.
