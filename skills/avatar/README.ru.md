# avatar

Робот твоего агента. Тело робота это харнес (Claude Code, Codex, Cursor и другие), голову модель делает себе сама из набора деталей: цвет и глаза. Весь робот одного цвета, мелкие детали темнее, на лбу лента с именем модели, на груди стикер компании модели.

Поставить: отправь агенту строку

> Установи этот скилл глобально: `https://github.com/serejaris/personal-corp-os/tree/main/skills/avatar`

и потом в штабе:

```
/avatar
```

- Узнаёт харнес и модель, проверяет, есть ли уже робот в `stack/avatars.json`.
- Робота нет: модель выбирает себе голову по характеру и говорит одной строкой, почему такую.
- Сохраняет робота в `stack/avatars.json` и кладёт в штаб страницу `avatar/robot.html`: робот за своей партой в штабе (файлы, полка скиллов, предметы MCP), вокруг отделы штаба комнатами с вывесками, внизу маленькая полоса четырёх ракурсов. Имена штаба лежат рядом в `avatar/robot-data.js` (имена, относительные пути `.env*` и состояние git, без содержимого файлов и адресов репозиториев); `avatar/` дописывается в `.gitignore` штаба. Открывается двойным кликом, без сервера и интернета.
- Двери показывают git и приватность GitHub; на стене по одному ключу на настоящий `.env*`, включая вложенные файлы. Ключи латунные; красные означают файл при GitHub, который git не игнорирует. Данные остаются на локальной странице и в inventory урока не входят. Без `gh` или при ошибке проверки приватности виден замок без таблички.
- На уроке Personal Corp: `/avatar <ссылка входа с экрана урока>`, робот входит в живой класс и горит маячком, пока агент работает. Адрес сервера урока приходит только в этой ссылке.

Нужен Python 3. Файлы: `SKILL.md` (шаги агента), `avatar.py` (набор, проверка выбора, превью), `pc3live.py` (вход в класс урока), `robot.html` (плеер превью; сторонние лицензии в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)). Скилл вызывается только командой.
