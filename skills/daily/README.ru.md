# daily

Дневной фокус штаба. Читает открытые задачи всех отделов и пишет в штабе файл дня `tasks/ГГГГ-ММ-ДД.md` со ссылками на задачи.

```
/daily
```

Или словами: «что сегодня», «план на день», «задачи на сегодня».

- Узнаёт из файла правил штаба (`CLAUDE.md` или `AGENTS.md`), где лежат задачи каждого отдела; если там не указано, останавливается и предлагает дописать по строке на отдел.
- Читает локальные `tasks/*.md` или внешний источник, например GitHub Issues; принятые, завершённые и снятые задачи пропускает.
- Кладёт каждую открытую задачу в один раздел: ждёт твоего решения, просрочено или заблокировано, в работе, остальное открытое.
- Пишет или обновляет файл дня, твои заметки в нём сохраняет.
- Отвечает до 7 строк: что ждёт твоего решения, 1-3 задачи на сегодня, путь к файлу дня.

Задачи отделов не меняет, задачи, сроки и пути не придумывает.
