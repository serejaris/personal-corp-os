# Daily

Запускается из штаба. Отвечает на вопрос «что делать сегодня» по задачам всех отделов.

## Правило данных

Каждый запуск читает файлы задач заново. Своей копии задач не держи и не опирайся на прошлые ответы в чате. Файл дня это срез со ссылками, источник правды остаётся в задачах отделов.

## Шаги

1. Определи сегодняшнюю дату из системного времени.
2. Прочитай файл правил штаба (`CLAUDE.md` или `AGENTS.md`). Найди строки, где лежат задачи отделов, например:
   `Обучение: ../corp-learn. Задачи отдела лежат в ../corp-learn/tasks/.`
3. Если таких строк нет, остановись. Скажи, что в правилах штаба не указано, где лежат задачи отделов, и предложи дописать по строке на отдел в формате выше. Пути не угадывай.
4. Для каждого отдела прочитай его файл правил и папку задач:
   - локальные файлы: читай `tasks/*.md`, кроме `README.md` и `_template.md`;
   - внешний источник (например GitHub Issues через `gh`): читай оттуда, если доступно;
   - если источник недоступен, запомни отдел как «не прочитано» с причиной.
5. Отбрось задачи со статусом «принято», «завершена» или «снята».
6. По каждой открытой задаче возьми из записи: состояние, следующий шаг, что ждёт решения человека. Если поля нет, пиши «не указано», не додумывай по тексту.
7. Разложи задачи по разделам, каждая задача ровно в один:
   - «Ждёт решения человека»;
   - «Просрочено или заблокировано»;
   - «В работе»;
   - «Остальное открытое».
8. Запиши или обнови файл дня в штабе `tasks/<ГГГГ-ММ-ДД>.md`. Если папки `tasks/` нет, создай её. Если файл дня уже есть, замени срез задач и сохрани заметки человека.

## Файл дня

```markdown
# ГГГГ-ММ-ДД

## Ждёт решения человека
- <отдел> · <задача>: <какое решение нужно> · [файл](../../corp-learn/tasks/<файл>.md)

## Просрочено или заблокировано
- <отдел> · <задача>: <дата или блокер> · <ссылка>

## В работе
- <отдел> · <задача>: <следующий шаг> · <ссылка>

## Остальное открытое
- <отдел> · <задача>: <состояние> · <ссылка>

## Не прочитано
- <отдел>: <причина>
```

Ссылки относительные от файла дня. Пустые разделы не пиши.

## Ответ в чат

Коротко, до 7 строк: сначала что ждёт решения человека, потом 1-3 задачи на сегодня, затем путь к файлу дня. Если какой-то отдел не прочитан, скажи об этом одной строкой.

## Запрещено

- менять статусы и содержимое задач отделов;
- придумывать задачи, сроки и пути;
- задавать вопросы до первого ответа.
