# it-memory

Находит и убивает хвосты процессов, которые держат память впустую: простаивающие сессии Claude Code в десктопе, хвосты закрытых приложений, сироты-воркеры, зомби. macOS и Linux.

## Какую проблему решает

Машина, на которой работают десятки агентских сессий, постепенно забивается: сессии Claude Code простаивают сутками, демон закрытого приложения живёт дальше, дублируются брокеры воркеров, висит забытый dev-сервер. Каждый держит 30–400 MB, вместе они загоняют машину в своп.

Скилл делит работу на два шага:

1. Скрипт только для чтения (`scripts/tails-macos.sh`, `scripts/tails-linux.sh`) выводит кандидатов: память, возраст, класс и что умрёт вместе с процессом, плюс своп и давление памяти. Без sudo, ничего не убивает.
2. Агент решает вместе с вами. Простаивающие сессии (нет активности 12 ч, не running) и хвосты закрытых приложений убиваются по вашему слову, про dev-серверы и всё непонятное агент спрашивает. Убивает проходом TERM → KILL и снимает замер заново.

Скилл объясняет, когда памяти правда мало (уровень давления и растущие swapouts), а когда «занято 15 GB свопа» значит только то, что macOS держит своп до перезагрузки.
