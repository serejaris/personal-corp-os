# daily-retro (экспериментальный)

Каждый вечер логи ваших агентов отвечают на два вопроса: что сегодня сделано и что осталось недоделанным. Скилл читает журналы сессий Claude Code и Codex на вашей машине, добавляет состояние git каждого затронутого репозитория, выписывает хвосты и подбивает их, как скилл manager.

Экспериментальный: в активные скиллы плагина не входит. Ставится копированием:

```bash
cp -R experimental/skills/daily-retro ~/.claude/skills/daily-retro
```

Попробовать: `python3 ~/.claude/skills/daily-retro/scripts/collect.py` печатает сводку за сегодня. Потом `/daily-retro` в штабе пишет `retro/daily/<дата>.md`. Чтобы запускался сам каждый вечер — шаблон из `automation/`.
