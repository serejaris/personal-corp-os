# Experimental skills

Skills that are being tried in real work and may change shape. They are not in the plugin's active list (`skills/`); copy a folder into `~/.claude/skills/` to use one. A skill graduates to `skills/` after it has run for a few weeks without changes to its steps.

| Skill | What it does |
|---|---|
| [daily-retro](skills/daily-retro/) | Every evening reads your agents' logs, lists what was done and what was left open, closes the tails |
